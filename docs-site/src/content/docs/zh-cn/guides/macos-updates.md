---
title: NexCode macOS 桌面版更新
description: 安装首个支持 OTA 的 Mac 版本，并在应用内升级。
---

macOS 1.0.1 新增启动时检查更新，以及应用菜单和菜单栏图标中的“检查更新…”入口。
请先从 [GitHub 发布页](https://github.com/jasonlee539/NexCode/releases/tag/v1.0.1)
手动安装 1.0.1；旧版 1.0.0 没有 OTA 功能，无法自行升级。
升级前应将应用从 DMG 移入有写入权限的“应用程序”目录。

当稳定版本提供当前 Mac 架构的升级资源时，NexCode 会征求确认，然后下载、验证并重启。
客户端验证数字签名、SHA-256、文件大小、版本和架构，拒绝不完整或校验失败的资源。
仅包含 Windows 资源的发布会被跳过。

安装程序将旧应用保留在 NexCode 旁边；如果新版管理服务不能启动，会恢复旧应用。
账号、配置和线程数据不会被升级包覆盖。下载包使用临时代码签名，OTA 数字签名不代表
Apple Developer ID 签名或公证。

本版还提供原生 Markdown 保存对话框，并同步 Windows 的账号切换改进。
确认切换后，NexCode 先停止 Codex 进程，再通过加密配置库更新登录凭据。
旧版本添加的账号可能需要重新登录一次；切换完成后请重新打开 Codex。
